# Emman Karimi — Personal Portfolio

A premium, handcrafted personal portfolio for **Emman Karimi** (Software Engineer, ICT Professional, and Graphic Designer based in Kenya). Built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Features
- **Obsidian Craft Design System**: Low-key dark aesthetic with electric amber accents, tactile glass surfaces, and editorial typography.
- **Editable Content Architecture**: Personal information, bio, social links, and skills live inside `client/src/content/profile.ts`.
- **Reusable Project Data**: Featured projects (NetFusion AI, Discipline OS, Trading Journal Pro, Freshvibe Graphics) are managed in `client/src/content/projects.ts` with interactive case study modals.
- **Replaceable Visual Assets**: Portraits and visual references are easily swapped without touching component code.
- **100% Independent Ownership**: Zero vendor lock-in or proprietary platform dependencies. Fully compatible with Windows 10, Git Bash, and VS Code.

## Quick Start
